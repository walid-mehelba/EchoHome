<h1 align="center">🏠 EchoHome</h1>

<p align="center">
  An e-commerce furniture website with a unique <b>trade-in feature</b> that lets customers exchange old furniture for new. 
  Refurbished items are resold sustainably — combining design, technology, and eco-friendly values.
</p>

---

## Project Idea

The goal is to design a user-friendly, visually appealing, and accessible website that addresses real user needs while applying **design thinking** principles.  
The project covers the **full design process** — from research and ideation to wireframes, prototypes, and final high-fidelity designs — delivering a functional, well-structured, and user-centered experience.

## Work Plan

1. **Research & Analysis**
   - Competitor analysis  
   - 7-key features analysis  
   - SWOT Analysis  
   - User Persona  
   - Card Sorting  
   - Sitemap  
   - User Flow  

2. **Visual Identity**
   - Color palette & typography  
   - Style guide  

3. **Main Designs**
   - Low-, Mid-, and High-fidelity designs  
   - Mobile app design  

4. **Review & Finalization**
   - Team review and improvements  
   - Export & delivery specs  

5. **Final Presentation**
   - Presentation Figma  
   - Presentation PDF  
   - Upload to GitHub
